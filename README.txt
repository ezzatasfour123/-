طريقة عمل الـ APK (من غير Android Studio)
=========================================
1) اعمل حساب على github.com (مجاني) وأنشئ Repository جديد.
2) ارفع كل محتويات المجلد ده على الـ Repository (الملفات وفولدر www وفولدر resources وفولدر .github).
   - فولدر .github مخفي أحياناً. لو مظهرش، من GitHub اختار Add file > Create new file
     واكتب في الاسم:  .github/workflows/build-apk.yml  وانسخ جواه محتوى الملف.
3) افتح تبويب Actions > Build APK > Run workflow. استنى 5-10 دقايق.
4) افتح التشغيلة اللي خلصت، ونزّل jadwali-apk من Artifacts (بيجي ملف zip، فكّه هتلاقي app-debug.apk).
5) انقل الـ APK للموبايل وثبّته (اسمح بالتثبيت من مصدر غير معروف).

بعد التثبيت على الموبايل:
- افتح التطبيق، الإعدادات > "اسمح بالإشعارات" واسمح بالإشعارات والمنبهات الدقيقة.
- فعّل "تذكير" أو "رنين" على مواعيدك (المنبهات > طبّق التذكير على كل المواعيد من الإعدادات).
- من إعدادات الموبايل: البطارية > التطبيق > "بدون قيود"، وإلا ممكن النظام يأخّر التنبيهات.
